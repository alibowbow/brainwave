# Brainwave · Ritual Studio

집중, 회복, 수면을 위한 로컬 퍼스트 오디오 스튜디오입니다. 바이노럴/아이소크로닉 리듬, 실제 CC0 현장 녹음, 절차형 Web Audio를 하나의 반응형 PWA에서 조합합니다.

## 제품 경험

- 시간대, 오늘 목표의 남은 시간, 최근 45일 세션 만족도와 컨디션 변화를 함께 반영하는 적응형 오늘 추천
- 추천 루틴의 목표 맞춤 재생 시간, 추천 근거, 한 번에 시작할 수 있는 대안 루틴 제공
- 검색·카테고리·즐겨찾기·사용자 저장 루틴을 갖춘 라이브러리
- 시간, 뇌파, 재생 방식, 환경음, 볼륨, 수면 페이드를 한 화면에서 조정하는 세션 스튜디오
- 진행률, 호흡 가이드, 실시간 믹서를 갖춘 방해 없는 집중 콘솔
- 장면 오브젝트를 직접 눌러 35개 자연음 레이어를 조합하는 리빙 사운드스케이프
- 깊은 집중 루틴의 실시간 3D 서재: 유리창을 타고 흐르는 빗방울 시뮬레이션, 렌즈처럼 도시를 비추는 물방울, 보케 야경, 스탠드 조명의 부드러운 그림자를 three.js로 렌더링하고 기기 성능에 맞춰 해상도를 자동 조절
- 파도 해변 루틴의 유화 바다: 여름 한낮의 만(灣)과 곶을 three.js로 실제 3D 장면(얕은 곳은 모래 바닥과 햇빛 일렁임이 비치는 에메랄드빛에서 먼 바다의 깊은 파랑으로 이어지는 물, 파도마다 해 쪽 면은 밝고 반대쪽은 그늘진 입체감과 먼 바다까지 반짝이는 윤슬, 파도 묶음이 구간마다 부서지며 잔거품 결이 보이는 흰 물거품과 흩어지는 거품 줄을 남기는 바다, 바람 방향으로 천천히 흘러가는 듬성한 흰 뭉게구름과 땅·바다 위를 함께 지나가는 구름 그림자, 밭과 산울타리·숲이 있는 초록 언덕과 마을·농가, 풀잎과 이삭이 한 가닥씩 보이는 풀밭에 군데군데 핀 데이지·미나리아재비·분홍 아르메리아와 그 위로 지나가는 돌풍 자국, 솔잎 다발과 솔방울이 보이는 바람에 흔들리는 소나무, 결과 금·지의류·따개비가 있고 젖은 면이 하늘을 되비치는 회색 바위, 만 위를 맴도는 갈매기, 등대가 선 곶 너머로 겹겹이 멀어지는 흰 절벽의 곶들과 푸른 산맥, 만을 오가는 돛단배)으로 시뮬레이션하고, 매 프레임을 이방성 쿠와하라 필터와 형태를 따라 흐르는 붓 자국으로 유화처럼 다시 칠함(가까운 것은 가는 붓, 먼 것은 굵은 붓), 따뜻한 햇빛과 푸른 보랏빛 그늘, 코발트에서 에메랄드로 이어지는 바다로 환하고 풍부한 색을 냄. 화면을 좌우로 끌면 넓은 그림 위를 옮겨 보듯 풍경이 옆으로 조금 흐르고(놓으면 천천히 제자리로), 파도 소리 볼륨에 따라 부서지는 파도가 늘거나 줄어듦. 기기 성능에 맞춰 해상도·붓질 품질을 자동 조절
- 하루 목표, 연속 기록, 7/30일 추이, 컨디션 변화를 보여주는 리포트
- 모든 화면과 재생 중인 루틴에 `#` 주소가 있어 링크 복사·공유·북마크·새로고침 가능 (예: `#/play/focus`, `#/play/amb/cosmic`, `#/insights`). 링크로 연 루틴은 즉시 자동재생을 시도하며, 브라우저가 소리를 차단하면 안내의 재생 버튼을 한 번 눌러 시작 (허용 전에는 타이머·기록이 진행되지 않음)
- 계정 없이 동작하는 로컬 저장, JSON 백업/복원, 설치형 PWA, 오프라인 오디오 캐시
- 다크 모드, 키보드 포커스, 터치 타깃, 움직임 줄이기 지원

## 적응형 추천

홈의 오늘 추천은 고정된 인기 순위가 아닙니다. 현재 시간대에 맞는 후보를 먼저 좁힌 뒤, 이 기기에 저장된 최근 세션의 만족도, 전후 컨디션 변화, 바로 직전에 사용한 루틴, 오늘 목표의 남은 시간을 조합해 순서를 정합니다. 목표가 얼마 남지 않았다면 기본 루틴을 무리 없이 끝낼 수 있는 길이로 줄이고, 목표를 이미 채웠다면 회복 중심의 선택을 우선합니다.

추천 계산은 외부 계정이나 서버로 기록을 전송하지 않고 브라우저 안에서만 이루어집니다. 기록이 아직 부족할 때는 시간대 기반 기본 추천으로 자연스럽게 폴백합니다.

## 오디오 아키텍처

`services/audioEngine.ts`의 단일 엔진이 뇌파 리듬, 절차형 사운드, 지연 로드한 현장 녹음을 믹싱합니다. 자연음은 디코딩 버퍼를 제한된 캐시에 보관하며, 샘플 로딩에 실패하면 하이브리드 레이어는 절차음으로, 사용자 녹음 전용 레이어는 같은 파일의 브라우저 미디어 경로로 재시도합니다. 천둥 같은 이벤트 음원은 불규칙 원샷으로, 연속 베드는 루프 경계 크로스페이드로 재생합니다.

오디오 원본, 라이선스, 가공 명령, 측정값과 SHA-256은 [THIRD_PARTY_AUDIO.md](./THIRD_PARTY_AUDIO.md)에 기록되어 있습니다.

## 로컬 실행

Node.js 20 이상을 권장합니다.

```bash
npm install
npm run dev
```

품질 검증:

```bash
npm run typecheck
npm test
npm run build
npm run check:bundle
npm run verify:focus   # 미리보기 서버(4173)를 띄운 뒤 실시간 3D 장면 확인
npm run verify:sea     # 미리보기 서버(4173)를 띄운 뒤 유화 바다 장면 확인
npm run verify:links   # 미리보기 서버(4173)를 띄운 뒤 화면·루틴 주소 확인
```

## 배포

Vercel은 저장소 루트를 Vite 프로젝트로 가져오면 됩니다. `vercel.json`에 빌드 명령과 `dist` 출력 경로가 정의되어 있으며 런타임 환경 변수는 필요하지 않습니다.

GitHub Pages는 `.github/workflows/deploy-gh-pages.yml`이 `main`을 빌드합니다. 저장소 하위 경로로 배포할 때만 `VITE_BASE_URL=/brainwave/`를 사용합니다.

## 안전 안내

바이노럴 리듬은 좌우 채널 차이를 사용하므로 헤드폰에서 가장 의도에 가깝게 들립니다. 편안한 낮은 볼륨으로 시작하고 운전이나 위험한 작업 중에는 사용하지 마세요. 이 앱은 의료기기가 아니며 진단이나 치료를 대신하지 않습니다.
