# Night Fires — asset provenance

These three worlds use independently authored procedural 3D geometry, original shaders and generated-at-runtime material maps. No downloaded/generated image, model, recording, licensed character, copyrighted game asset, or third-party demo source is included. Textures are small canvas maps made by `scenery.ts` and disposed with the owning scene.

JEV Sonnet and Opus galleries were studied for technique and live behavior only. Their source repositories had no verified reuse grant; no code or assets were ported. Concrete observed/adopted/rejected techniques are recorded in the group's `REFERENCES.md`.

No standalone audio is created. Audio recommendations and bounded interaction payloads belong to the existing Brainwave engine; see the integration guide.
